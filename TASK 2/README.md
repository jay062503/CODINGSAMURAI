# Sentiment Analysis on Social Media Posts

A lightweight NLP project that analyzes social media posts using **TextBlob** and **VADER Sentiment Analysis**. The project performs tweet preprocessing, sentiment classification (Positive, Negative, Neutral), exploratory data analysis, and visualization through sentiment distributions and word clouds.

# Features

* Text cleaning and preprocessing
* Stopword removal and tokenization
* Sentiment analysis using VADER & TextBlob
* Sentiment distribution visualizations
* Word cloud generation
* Data quality checks and exploratory analysis

# Tech Stack

Python, Pandas, NumPy, NLTK, TextBlob, VADER, Matplotlib, Seaborn, WordCloud

# Outcome

Built an end-to-end sentiment analysis pipeline capable of extracting insights from social media text and visualizing public sentiment trends.
